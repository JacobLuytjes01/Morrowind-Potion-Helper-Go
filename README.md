# Morrowind Potion Helper (Go)
A web app designed to help people find the right ingredients for potion recipes in The Elder Scrolls III: Morrowind.

Built with Go, HTML, and CSS.

## Features
**No Client Side JavaScript**

**Light Mode and Dark Mode**

## How to Run the Tool
Run ```go run main.go``` in the directory
